## 📋 Volunteer cheat-sheet (do NOT print on family-facing copy)

**At check-in:**
1. Greet family, hand them this waiver + a pen + clipboard
2. While they fill it out, hand kids name stickers
3. When they return it: **check Section 2 carefully**. If yellow/red allergy → write child's name + allergy on the day-of **allergy whiteboard** at the food prep station
4. If they checked **"NO" on photo release** (Section 5) → give the child a **red wristband** so volunteers/camera people can spot them at a glance
5. File the signed waiver in the binder (keep alphabetically by parent last name)

**After the event:**
- Take a photo of each signed waiver as backup (Google Drive folder)
- Keep the physical binder for **3 years** minimum

**Forgot waiver:**
- Have spare blank copies + extra pens at check-in
- Don't let any child participate in cooking/eating activities without a signed waiver — friendly but firm
